# 🌾 AgriTech – AI-Powered Smart Farming Platform

AgriTech is a **multilingual web application** designed to help farmers make **data-driven agricultural decisions** using **AI-powered crop and fertilizer recommendations** based on real-time data.

---

## 🚀 Problem Statement

Farmers often face challenges such as:
- Lack of real-time weather and soil insights
- Difficulty choosing the right crop and fertilizer
- Limited digital accessibility due to language barriers

This leads to **low productivity and poor decision-making**.

---

## 💡 Solution

AgriTech addresses these problems by providing:
- 🌱 **AI-based crop & fertilizer recommendations**
- 🌍 **Multilingual user interface** for better accessibility
- ☁️ **Real-time weather data integration**
- 🤖 **AI-powered advisory system** using Gemini API
